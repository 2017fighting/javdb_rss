## Agent skills

### Issue tracker

Issues, specs and wayfinder tickets live as markdown under `.scratch/<effort>/`.
See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles; every label string equals its name
(`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`).
See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: the glossary is `CONTEXT.md` (the `## Language` section) and
decisions live in `docs/adr/`. See `docs/agents/domain.md`.
