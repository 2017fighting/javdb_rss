# 02 — `/collected` 的截断不再静默

**What to build:** `/collected` 按页拉取收藏列表，翻页有上限。收藏数一旦超过上限，它会**静默返回一份不完整的列表** —— 用户无法分辨「我就收藏了这么多」与「服务只读到了这么多」。这是本服务唯一会静默少给数据的地方，也正是本项目反复要避免的那一类失败。交付：达到上限时给出明确信号。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 达到翻页上限时，响应里有**可机读的明确信号**，而不是照常 200 + 残缺列表
- [ ] 有测试构造超限场景并断言该信号出现
- [ ] 未达上限时响应**不含**该信号（不能是一个永远为真的字段）
- [ ] 上限的取值有据可依：先实测上游分页的每页条数，再决定留多少余量
