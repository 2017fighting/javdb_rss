# 04: 女优标签区

**Spec:** [`../spec.md`](../spec.md)

**What to build:** 「某位女优的标签」模式：选一位女优（或直接手输 id）→ 取她自己的标签 → 按词表反查落到上游分组上。基本组只列**她支持的**那几个主属性；标签上限 5，触顶时未选中的点不动并说明这是上游硬限制；分组可折叠、可搜索；年份是**精确的整年**（选项文字不带「起」），选了年份就让「追新」让位并说明原因。

没有 token 时这一区照旧可用 —— 标签词表与女优标签都是匿名可读的，不该被「收藏读不到」连坐。

**Blocked by:** 01, 02, 03

**Status:** ready-for-agent

- [ ] 分组名与分组顺序原样来自词表；组内标签来自她自己的 `tags[]`
- [ ] id 撞号时按**名字**消歧（月份 1–12 与真标签 id 全撞号）；对不上就不显示 —— 宁缺勿错
- [ ] 基本组只列她的 `filter_tags` 字母，不是词表里全部 6 个
- [ ] 标签上限 5：第 6 个点不动（并说明是上游限制）；触顶有解释文字；每组带已选计数
- [ ] 分组默认折叠，可搜索（搜索时全展开）、可全部展开；「有已选」的组默认展开
- [ ] 年份是整年、选项文字不带「起」；选了年份 `since` 让位且页面上说明为什么
- [ ] 标签与主属性按**词表顺序**拼进 URL：同样的选择永远得到逐字符相同的链接
- [ ] 切人时去取她的标签并有加载态；取不到要有说法，不能永远显示「?」
- [ ] 手输一个不在收藏列表里的 id 仍然能出标签与链接
- [ ] 生成的订阅 URL 里只有语义参数（`main` / `tags` / `year` / `since` / `pages`），没有 `filter_by`
- [ ] `tools/flows.mjs` 新增对应断言并通过
