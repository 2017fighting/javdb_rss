# 05: 全站标签订阅区

**Spec:** [`../spec.md`](../spec.md)

**What to build:** 「全站标签」模式：不挂任何实体。片库进 URL 路径、看得见也改得动（四个片库 —— 写错片库不报错，只会给另一个库的作品）；标签、年份、月份、时长各占掩码的一个槽位，但**由服务构造**，页面只发语义参数；`m`（含磁鏈）总是并进主属性（不发它时上游返回的作品全都没有磁链，会得到一条看着坏了的空 feed）；月份与时长只在此模式可用，女优模式下禁用并说明原因；切换模式时把只属于另一模式的控件状态清掉。

词表按片库取，不是写死快照。

**Blocked by:** 01, 03, 04

**Status:** ready-for-agent

- [ ] 模式切换时清掉另一模式专属的状态（不留「界面上选着、链接里没有」）
- [ ] 片库四选一、可见可改；换片库时词表跟着换（`type=2` 与 `type=0` 返回不同的分组）
- [ ] 主属性总是含 `m`：已有 `c` 时是并进去（`c,m`），不是覆盖
- [ ] 月份与时长在全站模式可用；切回女优模式时被禁用并说明原因（掩码尾部未验证）
- [ ] 切换片库/年份/月份/时长后 URL 逐字符正确，且**不含** `filter_by`
- [ ] 页面上的说明与当前模式一致（全站模式的标签走掩码槽位，不是独立参数那套）
- [ ] `tools/flows.mjs` 新增对应断言并通过
