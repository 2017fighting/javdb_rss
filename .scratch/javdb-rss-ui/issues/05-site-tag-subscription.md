# 05: 全站标签订阅区

**Spec:** [`../spec.md`](../spec.md)

**What to build:** 「全站标签」模式：不挂任何实体。片库进 URL 路径、看得见也改得动（四个片库 —— 写错片库不报错，只会给另一个库的作品）；标签、年份、月份、时长各占掩码的一个槽位，但**由服务构造**，页面只发语义参数；`m`（含磁鏈）总是并进主属性（不发它时上游返回的作品全都没有磁链，会得到一条看着坏了的空 feed）；月份与时长只在此模式可用，女优模式下禁用并说明原因；切换模式时把只属于另一模式的控件状态清掉。

词表按片库取，不是写死快照。

## Comments

已实现，没有动服务端代码 —— 全站 feed（`/rss/tags/{zone}.xml`）与词表端点
（`/tags?type=`）在票 01 与更早的「全站订阅」里已经就位，本票只把它们接到页面上。
页面侧在 `internal/webui/index.html` 与 `internal/webui/assets/app.js`，
断言在 `tools/flows.mjs`（76 → 124 项）与 `tools/a11y.mjs`（多跑一遍全站模式的 axe）。

几处值得记下的取舍：

- **「链接范围」（追新/全量）在全站模式下也真发出去。** 设计稿的 `siteUrl()` 只发
  `main/tags/year/month/duration`，不带 `since`/`pages` —— 但那个控件在两种模式下都
  可见，忽略它就是本票自己要消灭的那种「界面上选着、链接里没有」。所以追新 =
  `since=今天`、全量 = `pages=20`；并且**选了年份或月份就让 `since` 让位**
  （`since` 是本服务的本地下界，`year`/`month` 是上游精确筛选，同时发必然空 feed）。
  这是相对设计稿的一处有意偏离，票 08 回写文档时要一并改掉。
- **模式切换清的是「候选集不同」的那些状态，不只是「另一模式才有」的。** 标签与主属性
  在两种模式里来自不同的候选集（她的 `tags[]`/`filter_tags` ↔ 整份词表），留着旧选择
  就会出现「界面上没有、链接里有」，所以 `switchTagSource` 与换片库都清标签/主属性；
  月份与时长只在全站模式有槽位，切回女优模式清掉；**年份留着**（两种模式都是真筛选，
  且 `renderYear` 会用新词表校验它还在不在）。
- **`m` 的位置与服务端 `addMagnetsFlag` 对齐（补在最后：`c` → `c,m`）。** 页面显示的就是
  服务实际发的那条；`m` 那颗 chip 总是按下且不可取消，`title` 说清理由。
- **片库被 `feeds.zones` 白名单挡下时不给链接。** `/tags?type={zone}` 的 404 就是那个
  信号（与 `/rss/tags/{zone}.xml` 同一套语义）：页面禁用那颗 chip、不渲染它的标签，
  并说清「会 404 / 换一个 / 去改白名单」。502 与网络错误**不**这样处理 —— 那是暂时的，
  链接本身仍然有效。这条直接落在母 spec 需求 31「绝不给我一条点了就坏的链接」上。
- **月份/时长的单选 chip 用委派的点击 + 方向键，而不是启动时绑定的分段控件。**
  它们的选项随片库词表重渲染，启动时绑 listener 会随 DOM 一起被换掉。
- **`tools/a11y.mjs` 也改了**（票的清单只写了 `flows.mjs`）：全站模式的片库 chip、
  月份/时长 chip、掩码说明只在那个模式下可见，只在女优模式下跑 axe 会漏掉它们。
  这是测试覆盖而不是产品范围。

代码评审（standards + spec 两轴，并行 fresh 子代理）的结果与处置：

- standards 轴：无硬违规。三条基线异味**刻意保留**，理由记在这里：
  - `state.tagSource === "site"` 散在十余处 —— 两种模式确实有各自的
    候选集/掩码语义，抽一个策略对象只换来间接层（Speculative Generality），
    而这一屏的状态机本来就这么大。
  - `siteQueryPairs` 与 `tagQueryPairs` 同形：它们发的是不同的语义参数
    （月/时长只在一边），合并要靠条件插值，反而更难读。
  - `year/month/duration/zone` 离散字段成簇流转：与页面既有状态风格一致，
    收进一个对象会改动票 04 已经稳定的快照形状。
- spec 轴提了两条**真问题**，都已修：
  - `renderDuration` 没有像 `renderYear`/`renderMonth` 那样按新词表校验旧选择 ——
    从有码选了时长再切到没有那个档位的片库，`duration=` 会留在 URL 里而界面上没有对应 chip。
  - `renderTagUrl` 的参数提示在「全量」分支把年份/月份吞掉了（`if (all) … else if (year)`），
    而且全量模式下 `renderTagModeHint` 还在讲「since 让位」（它本来就不发 since）。
    已改成「链接范围」与「筛选维度」各说各的。
- spec 轴另提「清单未勾选」—— 本条在这份 Comments 落笔时一并勾上。
